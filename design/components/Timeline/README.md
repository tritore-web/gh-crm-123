La línea de tiempo lista las actividades del cliente o de la oportunidad: icono por tipo (llamada, mensaje, reunión o visita, nota), descripción, autor, fecha y hora.

- Las actividades solo se añaden. Un error se corrige con una nota nueva o anulando.
- Una actividad anulada queda visible, tachada y con la etiqueta «Anulada».
- La acción «Anular» aparece solo en las actividades propias que no están anuladas.
- Autor: un vendedor ve el nombre de sus propias actividades; las registradas por un supervisor se muestran solo como «Supervisor». Un supervisor ve siempre el nombre completo.
