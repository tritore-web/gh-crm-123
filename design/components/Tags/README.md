Las etiquetas nombran una etapa, un tipo o un estado con texto siempre visible.

- Etapas abiertas: tonos neutros cálidos `stage-nueva` … `stage-negociacion`. Solo Ganada (`success`) y Perdida (`danger`) usan color propio, con icono.
- Tipo de oportunidad: contorno `border-strong`, sin relleno.
- Nada de arcoíris: el color nunca es el único portador de significado.
- La insignia roja `badge` cuenta acciones atrasadas en la PWA.
