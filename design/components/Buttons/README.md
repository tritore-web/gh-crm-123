Los botones lanzan una sola acción por pantalla: `btn-primary` (fondo `primary`, texto blanco) para la acción principal, `btn-secondary` para el resto y `btn-ghost` para enlaces de fila.

- Un solo botón primario por vista o diálogo.
- Mientras se guarda, usa `is-loading` (indicador + deshabilitado) y cambia el texto a gerundio: «Guardando…».
- Archivar, Anular y Desactivar son secundarios: nunca rojos. «Cerrar como Perdida» lleva texto `danger` con icono.
- Móvil: 48 px de alto, mínimo `tap-min` (44 px).
- Para quitar algo de las listas, usa Archivar, Desactivar o Anular.
